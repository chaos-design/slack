The Art of Loop Engineering：把 Agent 能力做成多层反馈循环

文章从最小 Agent loop 出发：LLM 获取上下文、调用工具、重复直到任务完成。随后说明生产级 Agent 还需要验证循环保证质量、事件循环接入业务生态、hill climbing 循环利用 trace 改进 harness，并在各层保留合适的人类监督点。

原文：The Art of Loop Engineering

核心主张

先理解文章真正要解决的问题

可靠 Agent 不只是一个模型加工具，而是一组围绕任务、验证、触发和自我改进叠加起来的循环系统。
  • Loop 1 是基础 Agent：模型在上下文中反复调用工具直到完成任务。
  • Loop 2 增加 grader 和重试反馈，用 RubricMiddleware 或 after_agent hook 实现质量闭环。
  • Loop 3 把 Agent 接入 Slack、cron、webhook 等事件源，使其成为持续运行的系统组件。

结构速览

文章如何组织论证

01

基础 Agent Loop

第一层是最小可用 Agent：模型拿到上下文后选择工具、执行、读取结果，再决定下一步。工具让 Agent 可以对真实世界采取行动，例如克隆仓库、读写文档或打开 PR。

02

Verification Loop

第二层在 Agent 外包一层验证：grader 按 rubric 检查结果，失败时把反馈回传给模型重试。它会增加成本和延迟，但在生产质量优先的场景中通常值得。

03

Event-driven Loop

第三层把 Agent 从手工调用变成业务系统组件。事件可以来自 cron、webhook、Slack channel 或其他应用触发器，让 Agent 在后台持续响应真实工作流。

04

Hill Climbing Loop

第四层最关键：每次运行产生 trace，分析 Agent 从 trace 中找出模式，再改进 prompt、tool、grader 或其他 harness 配置。外层循环不只是重新运行任务，而是直接改进内层循环。

05

人类监督的位置

自动化并不等于移除人。文章强调，链接是否有效可由 grader 检查，但受众框架是否正确仍需要人类判断。金融交易、数据库操作等敏感动作也应要求人工确认。

06

四层循环的组合价值

最终表格把四层映射到 LangChain 原语：create_agent 自动化工作，RubricMiddleware 保证质量，LangSmith Deployment / Fleet 处理事件触发，LangSmith Engine 分析 trace 并改进 harness。

精读切片 · 1-3

基础 Agent Loop / Verification Loop

基础 Agent Loop

第一层是最小可用 Agent：模型拿到上下文后选择工具、执行、读取结果，再决定下一步。工具让 Agent 可以对真实世界采取行动，例如克隆仓库、读写文档或打开 PR。

At its core, an agent is a model calling tools in a loop until a task is complete. LangChain's create_agent gives this basic loop.

Verification Loop

第二层在 Agent 外包一层验证：grader 按 rubric 检查结果，失败时把反馈回传给模型重试。它会增加成本和延迟，但在生产质量优先的场景中通常值得。

A verification loop checks the agent's output against a rubric and sends feedback back to the model when it falls short.

Event-driven Loop

第三层把 Agent 从手工调用变成业务系统组件。事件可以来自 cron、webhook、Slack channel 或其他应用触发器，让 Agent 在后台持续响应真实工作流。

The event-driven loop connects the agent to an ecosystem: a schedule, webhook, or channel event triggers the agent in the backgro。

Hill Climbing Loop

第四层最关键：每次运行产生 trace，分析 Agent 从 trace 中找出模式，再改进 prompt、tool、grader 或其他 harness 配置。外层循环不只是重新运行任务，而是直接改进内层循环。

Traces from production runs feed an analysis agent that rewrites the harness configuration, improving prompts, tools, or graders.

Human oversight matters at natural decision points: sensitive tool calls, human grading, output approval, and harness changes bef。

Loop engineering stacks work automation, quality verification, event-triggered scale, and continuous harness improvement.
