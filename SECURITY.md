# Security Policy

## Supported Versions

This project is a static React application. Security fixes are applied to the
current `main` branch and released through the normal Vercel deployment flow.

## Reporting a Vulnerability

Please report security issues privately to the maintainers instead of opening a
public issue. Include:

- Affected route, resource, or generated HTML file.
- Steps to reproduce.
- Impact and any known exploit conditions.
- Suggested remediation, if available.

Do not include secrets, credentials, or private user data in reports.
